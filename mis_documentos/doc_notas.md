# Idea del Proyecto

  Actualmente existen múltiples aplicaciones para la creación de notas y recordatorios, pero muchas de ellas restringen ciertas funcionalidades a versiones de pago, lo que puede afectar negativamente la experiencia del usuario.

  Por ello, se propone el desarrollo de una aplicación móvil con el objetivo de mitigar estas limitaciones y brindar a los usuarios la posibilidad de gestionar sus notas y recordatorios de forma simple y eficiente.

  La aplicación contará con un modelo de negocio basado en una versión gratuita financiada mediante publicidad y una versión premium que ofrecerá beneficios adicionales. Las funcionalidades principales estarán disponibles para todos los usuarios, mientras que ciertas características avanzadas podrán estar sujetas a limitaciones o desbloquearse mediante una suscripción.

  El objetivo principal es proporcionar una herramienta intuitiva que facilite la organización de tareas y actividades diarias, mejorando la productividad y la gestión del tiempo de los usuarios.

  ---




  # Alcance del Proyecto

  El proyecto consiste en el desarrollo de una aplicación móvil para la gestión de notas, permitiendo a los usuarios organizar sus actividades personales, académicas y laborales mediante la creación de notas, programación de recordatorios, categorización de contenido y colaboración con otros usuarios.

  ## Funcionalidades Incluidas

  - Aplicación Android.
  - Registro de usuarios.
  - Creación de notas.
  - Programación de recordatorios.
  - Compartir notas con personas o grupos.
  - Asignación de niveles de prioridad.
  - Creación de categorías o grupos.
    - Estudios.
    - Hogar.
    - Trabajo.
    - Otras categorías personalizadas.
  - Visualización y administración de notas.
  - Notas flotantes que pueden superponerse sobre otras aplicaciones.

  ## Funcionalidades Futuras

  - Aplicación para iOS.
  - Copias de seguridad en la nube.

# Stakeholders

- Líder del Proyecto
    - Responsable de la planificación, coordinación y toma de decisiones del proyecto.
    - Supervisa el cumplimiento de los objetivos, tiempos y requerimientos por parte del equipo de desarrollo.

- Desarrolladores
    - Responsables del análisis, diseño, implementación y mantenimiento de la aplicación.
    - Desarrollan las funcionalidades de acuerdo con los requerimientos definidos para el proyecto.

- Usuarios Finales
    - Personas a quienes está dirigida la aplicación.
    - Utilizarán la aplicación para crear, organizar y administrar notas, recordatorios y grupos de trabajo.

# Actores

- Usuario
    - Persona que interactuará con el sistema para administrar sus notas.
