# Requerimientos No Funcionales

| Código | Categoría | Detalle |
|----------|----------|----------|
| RNF-01 | Disponibilidad | • La visualización y acceso a las notas deberá estar disponible de forma continua para el usuario. |
| RNF-02 | Rendimiento | • El tiempo de respuesta para consultar notas no deberá superar los 2 segundos.<br>• La aplicación deberá soportar al menos 100 notas por usuario sin degradación perceptible del rendimiento. |
| RNF-03 | Seguridad | • Las contraseñas deberán almacenarse utilizando algoritmos de cifrado seguros.<br>• Los usuarios únicamente podrán acceder a sus propios datos o a aquellos compartidos explícitamente. |
| RNF-04 | Almacenamiento | • El sistema deberá garantizar el uso eficiente de la memoria y del almacenamiento local o remoto. |
| RNF-05 | Escalabilidad | • La arquitectura deberá permitir la incorporación futura de funcionalidades como respaldo en la nube y compatibilidad con dispositivos iOS. |
| RNF-06 | Compatibilidad | • La aplicación deberá funcionar correctamente en dispositivos con Android 10 o superior. |
